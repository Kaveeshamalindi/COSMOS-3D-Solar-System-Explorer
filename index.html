About this project

COSMOS is a portfolio project demonstrating that convincing 3D-style scenes, orbital mechanics and interactive UI can be built without any rendering library or framework — just HTML, CSS and vanilla JavaScript. Every orbit, glow, ring and texture on this page is generated with plain CSS gradients, shadows and transforms.
